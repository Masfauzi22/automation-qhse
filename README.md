## 📋 Tentang Proyek

**QHSE Automation System** adalah aplikasi berbasis web yang dirancang untuk mengotomatisasi dan menyederhanakan pengelolaan data Quality, Health, Safety, and Environment (QHSE) di lingkungan perusahaan. Sistem ini membantu memantau kepatuhan keselamatan kerja, pelaporan insiden, manajemen inspeksi, serta dokumentasi standar operasional secara terpusat dan efisien.

## ✨ Fitur Utama

- **Manajemen Insiden & Hazard Report:** Pelaporan temuan bahaya dan investigasi insiden secara real-time.
- **Automated Compliance & Reporting:** Pembuatan laporan berkala terkait metrik keselamatan dan lingkungan kerja.
- **Audit & Inspeksi K3:** Jadwal dan checklist digital untuk inspeksi rutin di lapangan.
- **Dokumentasi QHSE:** Pengelolaan dokumen standar prosedur, kebijakan K3, dan sertifikasi.
- **Dashboard & Analitik:** Visualisasi data statistik performa QHSE perusahaan untuk pengambilan keputusan yang cepat.

## 🛠️ Tech Stack

- **Framework:** Laravel
- **Bahasa Pemrograman:** PHP 8.2+
- **Database:** MySQL / PostgreSQL
- **Frontend:** Blade / Bootstrap / Tailwind CSS (disesuaikan dengan implementasi Anda)
